# GCash Tracker

A web app for tracking GCash transactions, preventing duplicate claims, and monitoring daily income.

## Tech Stack
- React + Vite
- Tailwind CSS + TailAdmin
- Supabase (database & auth)

## Setup

1. Clone the repo and install dependencies:
```bash
npm install
```

2. Create a `.env` file:
```env
VITE_SUPABASE_URL=your-supabase-url
VITE_SUPABASE_ANON_KEY=your-anon-key
```

3. Run the app:
```bash
npm run dev
```
